Regularized reduced rank linear regression

8/30/2026

After deriving the solution to reduced-rank least squares, I was left dissatisfied with it. As I mention at the end of my previous note, reduced-rank regression does not reduce the risk of fitting noise. In the worst case, it extracts nothing but noise. The rank constraint resembles regularization, but it does not act as a regularizer in practice.

There can still be value in a reduced-rank fit. Suppose we have ppp features, qqq correlated targets, and n<pqn \lt pqn<pq data points. We would like to pool information across the targets through joint regression and summarize their relationship with the features using few parameters. This led me to ask whether reduced-rank regression can be combined with ridge regression to produce a parameter-efficient fit that is less sensitive to noise.

A nearly closed form for reduced-rank ridge

Once again, suppose we have data X∈Rn×pX\in \mathbb{R}^{n\times p}X∈Rn×p, targets Y∈Rn×qY\in \mathbb{R}^{n\times q}Y∈Rn×q, positive integer rank rrr, and a regularization parameter λ≥0\lambda\geq 0λ≥0. We want to find a matrix Θ∈Rp×q\Theta \in \mathbb{R}^{p\times q}Θ∈Rp×q that solves the problem

min⁡Θ.∥Y−XΘ∥F2+λ∥Θ∥F2s.t.rank(Θ)≤r. \begin{align} \min_{\Theta}. \quad & \|Y - X\Theta\|_F^2 +\lambda\|\Theta\|_F^2 \\ \text{s.t.} \quad & \text{rank}(\Theta) \leq r.\nonumber \end{align} Θmin​.s.t.​∥Y−XΘ∥F2​+λ∥Θ∥F2​rank(Θ)≤r.​​

Knowing the solution to the unregularized problem, a natural first attempt at (1) is to reuse the same recipe. Let Θ^\hat{\Theta}Θ^ solve the unconstrained ridge problem, take the thin SVD XΘ^=UΣVTX\hat{\Theta}=U\Sigma V^TXΘ^=UΣVT, and return Θ^V:rV:rT\hat{\Theta}V_{:r}V_{:r}^TΘ^V:r​V:rT​, where V:rV_{:r}V:r​ contains the first rrr columns of VVV. This is not a solution to (1), but it is close.

To find the real solution, first define

X~:=[XλI],Y~:=[Y0], \tilde{X}:=\begin{bmatrix}X \\ \sqrt{\lambda} I\end{bmatrix}, \quad \tilde{Y}:=\begin{bmatrix}Y \\ \mathbf{0}\end{bmatrix}, X~:=[Xλ​I​],Y~:=[Y0​],

where III is the p×pp\times pp×p identity matrix and 0\mathbf{0}0 is the p×qp\times qp×q matrix of zeros. We can now rewrite (1) as

min⁡Θ.∥Y~−X~Θ∥F2s.t.rank(Θ)≤r. \begin{align} \min_{\Theta}. \quad & \left\|\tilde{Y} - \tilde{X}\Theta\right\|_F^2 \\ \text{s.t.} \quad & \text{rank}(\Theta) \leq r.\nonumber \end{align} Θmin​.s.t.​​Y~−X~Θ​F2​rank(Θ)≤r.​​

Problem (2) carries no ridge term. It is exactly the reduced-rank least squares problem from before, with X~\tilde{X}X~ and Y~\tilde{Y}Y~ in place of XXX and YYY, and its unconstrained solution is Θ^\hat{\Theta}Θ^. Take the thin SVD X~Θ^=U~Σ~V~T\tilde{X}\hat{\Theta}=\tilde{U}\tilde{\Sigma} \tilde{V}^TX~Θ^=U~Σ~V~T. The two-step solution gives Θ^V~:rV~:rT\hat{\Theta}\tilde{V}_{:r}\tilde{V}_{:r}^TΘ^V~:r​V~:rT​ as a solution to (2), and therefore to (1).

The naive and the correct solutions differ only in which matrix we decompose, XΘ^X\hat{\Theta}XΘ^ in the first case and X~Θ^\tilde{X}\hat{\Theta}X~Θ^ in the second.

What does reduced-rank ridge achieve?

In this problem, λ\lambdaλ does double duty. First, the ordinary ridge fit shrinks Θ^\hat{\Theta}Θ^ and keeps it well behaved when XXX is ill-conditioned. Second, λ\lambdaλ changes which rank-rrr subspace we keep. The matrix X~Θ^\tilde{X}\hat{\Theta}X~Θ^ stacks λΘ^\sqrt{\lambda}\hat{\Theta}λ​Θ^ beneath XΘ^X\hat{\Theta}XΘ^, so the coefficients enter the decomposition directly rather than only through XXX.

To see how, note that the right singular vectors of X~Θ^\tilde{X}\hat{\Theta}X~Θ^ are the eigenvectors of

Θ^TX~TX~Θ^=Θ^T(XTX+λI)Θ^=(XΘ^)T(XΘ^)+λΘ^TΘ^. \hat{\Theta}^T\tilde{X}^T\tilde{X}\hat{\Theta} = \hat{\Theta}^T\left(X^TX + \lambda I\right)\hat{\Theta} = \left(X\hat{\Theta}\right)^T\left(X\hat{\Theta}\right) + \lambda\hat{\Theta}^T\hat{\Theta}. Θ^TX~TX~Θ^=Θ^T(XTX+λI)Θ^=(XΘ^)T(XΘ^)+λΘ^TΘ^.

The naive recipe keeps the leading eigenvectors of the first term alone. The correction λΘ^TΘ^\lambda\hat{\Theta}^T\hat{\Theta}λΘ^TΘ^ rewards directions in which the coefficients themselves are large, whether or not XXX excites them.

There is a tidier way to write the same matrix. The ridge normal equations say that

XT(Y−XΘ^)=λΘ^. X^T(Y - X\hat{\Theta}) = \lambda\hat{\Theta}. XT(Y−XΘ^)=λΘ^.

Unlike in least squares, the residual is not orthogonal to the column space of XXX. Its overlap is exactly λΘ^\lambda\hat{\Theta}λΘ^. Substituting and writing Y^=XΘ^\hat{Y} = X\hat{\Theta}Y^=XΘ^ for the fitted values gives

Θ^T(XTX+λI)Θ^=Θ^TXTY=Y^TY. \hat{\Theta}^T\left(X^TX+\lambda I\right)\hat{\Theta} = \hat{\Theta}^TX^TY = \hat{Y}^TY. Θ^T(XTX+λI)Θ^=Θ^TXTY=Y^TY.

Reduced-rank ridge therefore keeps the rrr directions in target space that account for the most cross-covariance between the fitted values and the targets. The naive recipe instead keeps the directions that account for the most variance in the fitted values. The two criteria agree when λ=0\lambda = 0λ=0, since Y^TY=Y^TY^+Y^T(Y−Y^)=Y^TY^\hat{Y}^TY = \hat{Y}^T\hat{Y} + \hat{Y}^T\left(Y - \hat{Y}\right) = \hat{Y}^T\hat{Y}Y^TY=Y^TY^+Y^T(Y−Y^)=Y^TY^ by the orthogonality argument from the previous note. Regularization pulls them apart.

How much does this move the answer? If XTX=cIX^TX = cIXTX=cI, then Θ^T(XTX+λI)Θ^=(c+λ)Θ^TΘ^\hat{\Theta}^T(X^TX+\lambda I)\hat{\Theta} = (c+\lambda)\hat{\Theta}^T\hat{\Theta}Θ^T(XTX+λI)Θ^=(c+λ)Θ^TΘ^. This has the same eigenvectors as Θ^TXTXΘ^\hat{\Theta}^TX^TX\hat{\Theta}Θ^TXTXΘ^, so the naive and correct recipes agree exactly. With orthogonal features of equal norm, λ\lambdaλ only shrinks. Away from that case, the correction has spectral norm at most λσ1(Θ^)2\lambda\sigma_1(\hat{\Theta})^2λσ1​(Θ^)2. A Davis–Kahan bound says the retained subspace can rotate appreciably only when this is comparable to the gap between the rrrth and (r+1)(r+1)(r+1)th eigenvalues of Y^TY^\hat{Y}^T\hat{Y}Y^TY^.

This estimator is not new. Mukherjee and Zhu (2011) derive it from the same augmented data. In extending the estimator to kernels, they write the projection in terms of the eigenvectors of YTX(XTX+λI)−1XTYY^TX(X^TX+\lambda I)^{-1}X^TYYTX(XTX+λI)−1XTY, which is the matrix Y^TY\hat{Y}^TYY^TY above. They also find empirically that the ridge penalty and rank constraint help each other most when the predictors are collinear. That is where the eigenvector calculation says the two effects of λ\lambdaλ interact.

Nuclear norm regularization

Ridge is not the only way to regularize this problem, and a hard rank constraint is not the only way to ask for a low-rank fit. The rank of Θ\ThetaΘ is the number of its nonzero singular values, so the constraint in (1) is a sparsity constraint on the spectrum. The usual convex substitute for a sparsity constraint is an ℓ1\ell_1ℓ1​ penalty. Applied to the singular values, this becomes the nuclear norm ∥Θ∥∗=∑iσi(Θ)\|\Theta\|_* = \sum_i \sigma_i(\Theta)∥Θ∥∗​=∑i​σi​(Θ) and gives the problem

min⁡Θ.∥Y−XΘ∥F2+μ∥Θ∥∗, \min_{\Theta}. \quad \|Y - X\Theta\|_F^2 + \mu\|\Theta\|_*, Θmin​.∥Y−XΘ∥F2​+μ∥Θ∥∗​,

and putting the ridge term back gives a matrix analogue of the elastic net,

min⁡Θ.∥Y−XΘ∥F2+λ∥Θ∥F2+μ∥Θ∥∗. \min_{\Theta}. \quad \|Y - X\Theta\|_F^2 + \lambda\|\Theta\|_F^2 + \mu\|\Theta\|_*. Θmin​.∥Y−XΘ∥F2​+λ∥Θ∥F2​+μ∥Θ∥∗​.

Since ∥Θ∥F2=∑iσi(Θ)2\|\Theta\|_F^2 = \sum_i \sigma_i(\Theta)^2∥Θ∥F2​=∑i​σi​(Θ)2, both penalties act on the spectrum and the analogy to the vector case is exact. The Frobenius term is ridge on the singular values and shrinks the spectrum smoothly. The nuclear term is lasso on the singular values and sets the small ones to zero. The nuclear norm is a soft rank constraint in the same sense that the lasso is a soft sparsity constraint. It also means that we need not choose rrr in advance because μ\muμ determines the rank. Nuclear-norm-penalized multivariate regression goes back to Yuan, Ekici, Lu, and Monteiro (2007), who proposed it for factor estimation and selection.

Both problems are convex, so we no longer need a special argument for a non-convex constraint. What we give up is the nearly closed form. These problems are still straightforward to solve. The proximal operator of the nuclear norm soft thresholds the singular values. For a matrix ZZZ with thin SVD UΣVTU\Sigma V^TUΣVT,

proxtμ∥⋅∥∗(Z)=U(Σ−tμI)+VT. \mathrm{prox}_{t\mu\|\cdot\|_*}(Z) = U\left(\Sigma - t\mu I\right)_{+}V^T. proxtμ∥⋅∥∗​​(Z)=U(Σ−tμI)+​VT.

Proximal gradient descent solves either problem by alternating a least squares gradient step with one of these thresholded SVDs. The ridge term needs no separate handling because stacking the data as before turns the elastic net problem into a pure nuclear norm problem in X~\tilde{X}X~ and Y~\tilde{Y}Y~.

An SVD per iteration sounds expensive next to the single SVD used by reduced-rank ridge. In practice, the later SVDs can be much cheaper than the first. Consecutive iterates are close, so the singular vectors from one iteration provide good starting points for the next. We also do not need the full decomposition. Only singular values above tμt\mutμ survive the threshold, and the rank of the iterates tends to settle early. It is enough to compute a few more singular triplets than the current rank and check that the smallest computed value falls below the threshold. The same warm starts help when computing a path of solutions over μ\muμ, which must usually be tuned. Mazumder, Hastie, and Tibshirani (2010) describe this machinery for matrix completion.

The two approaches also respond differently to a change in the loss. Suppose we weight the residuals entry by entry, replacing ∥Y−XΘ∥F2\|Y - X\Theta\|_F^2∥Y−XΘ∥F2​ with ∥W⊙(Y−XΘ)∥F2\|W\odot(Y - X\Theta)\|_F^2∥W⊙(Y−XΘ)∥F2​ for a matrix of weights WWW. The elastic net changes little. A weighted quadratic is still convex, and proximal gradient descent runs with a different gradient step. The rank-constrained problem falls apart. In the special case X=IX = IX=I, completing the square entry by entry gives

∥W⊙(Y−Θ)∥F2+λ∥Θ∥F2=∥W~⊙(Y~−Θ)∥F2+c, \left\|W\odot\left(Y-\Theta\right)\right\|_F^2 + \lambda\|\Theta\|_F^2 = \left\|\tilde{W}\odot\left(\tilde{Y}-\Theta\right)\right\|_F^2 + c, ∥W⊙(Y−Θ)∥F2​+λ∥Θ∥F2​=​W~⊙(Y~−Θ)​F2​+c,

where the squares and division are entrywise, W~2=W2+λ\tilde{W}^2 = W^2 + \lambdaW~2=W2+λ, Y~=W2⊙Y/(W2+λ)\tilde{Y} = W^2\odot Y/\left(W^2+\lambda\right)Y~=W2⊙Y/(W2+λ), and ccc does not depend on Θ\ThetaΘ. The ridge term has been absorbed into strictly positive weights. What remains under the rank constraint is weighted low-rank approximation, which Gillis and Glineur (2011) show is NP-hard even for rank one with strictly positive weights. Stacking cannot rescue us because its argument relies on the plain Frobenius norm. The closed form is much more brittle than the convex relaxation.

Nuclear norm plus a rank constraint

With both a soft rank penalty and a hard rank constraint on hand, it is natural to ask what happens if we impose them together,

min⁡Θ.∥Y−XΘ∥F2+μ∥Θ∥∗s.t.rank(Θ)≤r. \begin{align} \min_{\Theta}. \quad & \|Y - X\Theta\|_F^2 + \mu\|\Theta\|_* \\ \text{s.t.} \quad & \text{rank}(\Theta) \leq r.\nonumber \end{align} Θmin​.s.t.​∥Y−XΘ∥F2​+μ∥Θ∥∗​rank(Θ)≤r.​​

I do not know of an efficient algorithm that solves problem (3) globally, and there is no closed form. We are back to a non-convex problem, and this time nothing rescues it.

We can still write down a reasonable heuristic. The rank constraint and nuclear norm are both unitarily invariant. Their joint proximal operator uses a single SVD: truncate at rank rrr, then soft threshold what remains. For a matrix ZZZ with thin SVD UΣVTU\Sigma V^TUΣVT, that operator is

U:r(Σ:r−tμI)+V:rT. U_{:r}\left(\Sigma_{:r} - t\mu I\right)_{+}V_{:r}^T. U:r​(Σ:r​−tμI)+​V:rT​.

Proximal gradient descent with this step costs no more per iteration than the elastic net. Warm-started from the reduced-rank ridge solution, it behaves sensibly. What we lose is the guarantee. The iterates settle at a stationary point, with no assurance that it is global.

The two-step argument for ridge does not apply here. The orthogonality decomposition still works because it involves only the least squares term. It leaves us minimizing ∥XΘ^−XΘ∥F2+μ∥Θ∥∗\|X\hat{\Theta} - X\Theta\|_F^2 + \mu\|\Theta\|_*∥XΘ^−XΘ∥F2​+μ∥Θ∥∗​ under the rank constraint. The relaxation is what fails. We replaced XΘX\ThetaXΘ with a free matrix MMM, which requires every term to be a function of MMM. The nuclear norm of Θ\ThetaΘ is not. Ridge works because a squared Frobenius penalty is a sum of squares. Stacking folds it into the data before we relax anything. The nuclear norm has no such form.

The problem becomes tractable again if we penalize μ∥XΘ∥∗\mu\|X\Theta\|_*μ∥XΘ∥∗​ instead. Every term is then a function of MMM, so both steps go through. The solution has the form Θ^V:rDV:rT\hat{\Theta}V_{:r}DV_{:r}^TΘ^V:r​DV:rT​, where a diagonal DDD applies soft thresholding rather than leaving the retained singular values intact.

I do not know of a reason to prefer problem (3) to either of its neighbors. The rank constraint has already fixed the rank, so the nuclear norm cannot do the job it is best at. It can only shrink the rrr singular values we kept. Ridge does that without costing us the closed form. If we know rrr, reduced-rank ridge solves the problem exactly. If we do not, the matrix elastic net is convex and chooses the rank. Problem (3) gives up the closed form of the first and the convexity of the second without an apparent benefit.
